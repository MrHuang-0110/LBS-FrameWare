# 项目记忆

本目录是项目唯一记忆系统（2026-07-16 起启用，取代原知识图谱 MCP 记忆）。

## 文件索引

| 文件 | 记录内容 |
|------|----------|
| `pitfalls.md` | 踩过的坑：现象、根因、修复、验证位置 |
| `framework.md` | 项目框架：架构、模块、关键约定 |
| `knowledge.md` | 知识：方案、工具链用法、调试方法 |

## 使用规则

- **动代码前**：先查 `pitfalls.md` / `framework.md` 中与本改动相关的条目，避免重踩坑。
- **改动后**：遇到新坑、发现新框架事实、沉淀新知识时，**就地更新**对应文件（同一条目就地更新，不追加重复记录）。
- 记忆只记录事实与结论，不记录一次性操作过程。
